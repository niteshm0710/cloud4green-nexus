# VMware WebMKS SDK Assets

The official VMware WebMKS SDK is proprietary software under Broadcom licensing and is excluded from public version control.

To enable the HTML5 browser console:
1. Download or obtain the authorized WebMKS SDK v2.2.0 (Build 22342085) following the instructions in `docs/WEBMKS.md`.
2. Place the following files in this directory:
   - `wmks.min.js`
   - `jquery.min.js` (jQuery 2.2.0)
   - `jquery-ui.min.js` (jQuery UI 1.12.1)
   - `jquery-ui.min.css`
3. Custom styling and canvas framing are maintained in `wmks-all.css`.
